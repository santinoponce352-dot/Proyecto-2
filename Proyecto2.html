Documentación académica

Proyecto Tienda Online & Vibe Coding

Estructura Técnica

Desarrollado integralmente con HTML5, CSS (Tailwind CSS) y JavaScript ES6+ interactivo en un único documento autocontenido con almacenamiento persistente en localStorage.

Uso de Inteligencia Artificial (Vibe Coding)

Se utilizaron modelos de lenguaje avanzados para:

  • Diseñar la arquitectura del simulador de estado de pedidos e interfaz Tycoon.
  • Generación de assets SVG dinamizados y paleta de colores adaptable.
  • Optimización de funciones de filtrado, ordenamiento y carrito de compras en JS.

Publicación en GitHub Pages

  1. Crear repositorio en GitHub llamado: mi-tienda-online
  2. Subir este archivo como index.html y crear un README.md
  3. En GitHub: Settings ➔ Pages ➔ Select Source main branch / root ➔ Save.
